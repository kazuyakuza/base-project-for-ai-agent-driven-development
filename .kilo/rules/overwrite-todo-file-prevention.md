# Overwrite TODO File Prevention

- If you are editing a TODO file to add `[DONE]` and/or marking tasks as done, while following the critical workflow, then take care to don't remove or modify the rest of the file's content.
- If you are updating a TODO file **before** starting the critical workflow, or by a user request, then check that the file you are editing is correct (by checking it's content), or do you need to create a new one.
- When you create a new TODO file, first check if the file already exists or not. If already exist, then previously decide if you should create it with a different name.
- While following the critical workflow, and specially in any sub-step of it, if you decided to create a new TODO file with tasks (fixes, improvements, etc.) to resolve later, stop. Instead ask to your caller to decide how to proceed.
